【英文學習測驗：iPhone 離線版安裝說明】

一、上傳到網路上（只要做一次）
1. 在 GitHub 建立一個 Public 的 repository（例如 vocab-quiz）。
2. 把這個資料夾裡「所有檔案和資料夾」上傳（index.html、sw.js、manifest.webmanifest、icons 資料夾、data 資料夾）。
   注意：要上傳的是資料夾「裡面」的內容，index.html 必須在最外層。
3. Settings → Pages → Branch 選 main、資料夾選 / (root) → Save。
4. 等一兩分鐘，網址會是 https://你的帳號.github.io/vocab-quiz/

二、安裝到 iPhone（不需要 App Store）
1. 用 iPhone 的 Safari 打開上面的網址（一定要用 Safari）。
2. 先保持連網，等頁面完整載入（第一次會把全部題庫下載到手機）。
3. 點下方的「分享」按鈕 → 往下滑 → 「加入主畫面」→ 新增。
4. 之後從主畫面的圖示開啟，就是全螢幕的獨立 App，沒有網路也能使用。

三、更新題庫或程式之後
1. 修改 GitHub 上的檔案。
2. 打開 sw.js，把第一行附近的 CACHE = "vocab-quiz-v1" 改成 v2（每次更新加 1）。
3. 手機連網開啟一次 App（可能要關掉再開兩次），就會換成新版。

四、注意事項
- 網站不會記錄任何資料；你自己載入的題庫檔只存在當次畫面裡。
- iPhone 發音使用手機內建語音；英式、澳洲、加拿大口音需要手機裡有安裝對應語音（設定 → 輔助使用 → 語音內容）。
- 自動發音有時需要先點一下畫面才會出聲。
- 「小視窗」和「全螢幕」按鈕在手機上會自動隱藏（手機從主畫面開啟已是全螢幕）。
